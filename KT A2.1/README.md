# Portfolio - Lương Xuân Bắc

Trang portfolio cá nhân giới thiệu thông tin, kỹ năng, dự án và cách liên hệ với Lương Xuân Bắc. Giao diện được xây dựng bằng HTML và CSS thuần, có bố cục responsive và sử dụng các hình ảnh trong thư mục `assets/img/`.

## Chạy dự án

Không cần cài đặt thư viện hoặc build. Mở `index.html` trực tiếp bằng trình duyệt, hoặc dùng tiện ích máy chủ tĩnh như Live Server trong VS Code.

## Cấu trúc

```text
.
|-- index.html
|-- README.md
|-- Changelog.md
|-- test_report.md
`-- assets/
    |-- css/
    |   `-- styles.css
    `-- img/
```

## Nội dung

- Giới thiệu cá nhân và ảnh đại diện
- Danh sách kỹ năng
- Các dự án tiêu biểu
- Thông tin liên hệ và biểu mẫu liên hệ

Biểu mẫu hiện chỉ là giao diện HTML; chưa kết nối tới dịch vụ gửi dữ liệu. Các liên kết dự án đang là placeholder.
